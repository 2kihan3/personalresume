# 🏄 摇滚产品经理个人主页

一个炫酷的赛博朋克风格个人主页，以乐队为主题，展示个人简历、工作经历、项目案例等。

## ✨ 特性

- 🎸 **Loading Page** - 赛博朋克风格，吉他、音响连线动画
- 🎤 **主页面** - 乐队成员角色交互
- 🎬 **视频播放** - 每个角色点击播放对应视频
- 🎵 **音频同步** - 角色音效与视频同步
- 📄 **简历弹窗** - 视频结束后弹出可滚动的简历内容
- 🔇 **全局静音** - 一键静音所有音效
- 🎨 **赛博朋克风格** - 炫酷的视觉效果和动画

## 🎯 角色功能

| 角色 | 功能 | 内容 |
|------|------|------|
| 🎸 吉他手 | 个人简介 | 个人能力、技术栈、技能标签 |
| 🎸 贝斯手 | 工作经历 | 时间轴形式展示工作历史 |
| 🥁 鼓手 | 项目概述 | 公司项目 + 个人项目（tab切换） |
| 🎤 歌手 | 更多信息 | 基本信息、教育经历、常见问题 |

## 🛠️ 技术栈

- **HTML5** - 页面结构
- **CSS3** - 样式和动画
- **JavaScript** - 交互逻辑
- **GSAP** - 动画库
- **Tailwind CSS** - 样式工具
